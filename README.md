## 🚀 Key Topics Covered in Module 01: Web Requests
1. **HTTP Architecture:** Request/response lifecycle, status code classes (1xx–5xx), and headers (Request, Response, General, Security).
2. **Browser DevTools & Asynchronous Requests:** Inspecting network traffic, unmasking background `fetch()` calls, and analyzing raw HTTP data.
3. **cURL Mastery & Basic Auth:** Verbose inspection (`-v`), header extraction (`-I`), credentials handling (`-u`), and imitating browser requests.
4. **POST Requests & State Management:** Form-encoded vs JSON payloads, saving session cookies with cookie jars (`-c` / `-b`).
5. **CRUD REST APIs:** Interacting with endpoints via `GET`, `POST`, `PUT`, and `DELETE` without a frontend GUI.
